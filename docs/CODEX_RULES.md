# Codex Rules

Codex is reserved for:
- repo-wide implementation
- large refactors
- complex cross-file integration
- final validation passes
- workbook updates when precise repository-wide context is needed

Do not use Codex for:
- small markdown edits
- simple terminal troubleshooting
- minor UI adjustments
- isolated code cleanup

Codex 5-hour usage is currently exhausted. Conserve Codex.
