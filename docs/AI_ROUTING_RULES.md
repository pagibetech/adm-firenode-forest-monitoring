# AI Routing Rules

## ChatGPT
Use for:
- project direction
- debugging decisions
- workflow decisions
- interpreting logs and screenshots

## Roo Code + Kimi
Use for:
- small to medium edits
- markdown updates
- small Python fixes
- small frontend fixes
- local validation assistance

## Codex
Use only when:
- repo-wide implementation is required
- several files must be changed consistently
- final validation needs premium agentic coding

## Local Machine
Use for:
- builds
- flashing
- serial monitor
- hardware testing
